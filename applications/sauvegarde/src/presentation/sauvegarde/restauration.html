♻️ Restauration

Restaure une sauvegarde Nextcloud sur la machine de destination choisie ci-dessous (accès SSH root avec la clé de dimotic-ha). Étape 1 : arrêt et remplacement des éléments choisis, sans aucun redémarrage. Étape 2 : démarrage, après vérification.

① Connexion Nextcloud

Prérequis obligatoire : autoriser la clé SSH de ce dimotic-ha pour root sur la destination

La destination n'a besoin de rien d'autre (dimotic-ha, Docker, curl, tar : installés par l'étape 1 s'ils manquent). Sur une image fraîchement installée, root refuse souvent le mot de passe en SSH : utiliser alors la commande à coller sur la destination (en root ou via sudo -i).
