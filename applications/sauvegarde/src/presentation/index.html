📡 Importer depuis le gossip

Propose automatiquement un répertoire pour chaque machine dimotic-ha et chaque stack HA déjà connus par gossip (déploiements Docker) — à compléter ensuite (site, notamment, jamais connu du gossip). N'écrase jamais une entrée déjà présente.

🔒 Pousser le mot de passe Nextcloud

Écrit le mot de passe d'application Nextcloud sur le fichier hôte de la machine choisie, par SSH — jamais enregistré dans la configuration de cette application. Un mot de passe différent par machine (voir §3bis de la spec).

Procédure côté Nextcloud (une fois par machine)

  1. Se connecter à Nextcloud avec le compte utilisé pour les sauvegardes.
  2. Aller dans Paramètres personnels → Sécurité.
  3. Dans « Mots de passe d'applications », donner un nom qui identifie cette machine précise (ex. sauvegarde-ha2) — un nom différent à chaque fois, jamais le même mot de passe réutilisé entre plusieurs machines.
  4. Cliquer « Créer un nouveau mot de passe d'application ».
  5. Nextcloud affiche le mot de passe généré une seule fois — le copier immédiatement (impossible de le revoir plus tard).
  6. Choisir la machine correspondante ci-dessous, coller le mot de passe, puis « Pousser ».
