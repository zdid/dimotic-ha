Machines du site

☑ devant une machine : la machine est supervisée. Elle s'affiche ici, avec ses sauvegardes en face ; une de ses applications cochée qui s'arrête ou plante est signalée en rouge. Décochée, elle passe dans « Autres machines », pour mémoire seulement.

☑ devant une application (machine supervisée seulement) : application surveillée. Décochée, son arrêt n'est signalé qu'en orange, sans alerte.

Cocher une machine coche avec elle ses applications déjà annoncées. Chaque case est prise en compte aussitôt, sans bouton « Enregistrer », et vaut pour toutes les machines du site : la même sélection s'affiche partout. Une machine ou une application qui apparaît arrive décochée.
