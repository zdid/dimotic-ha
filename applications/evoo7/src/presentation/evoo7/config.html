Thermostat

Regroupe plusieurs données existantes (température ambiante, consigne, mode, éco, circulateurs) en une seule entité climate standard dans Home Assistant. Active automatiquement Consultation (et Mise à jour si disponible) sur les données nécessaires — les décocher manuellement ensuite n'est pas automatique.

Cocher "Consultation" pour recevoir la donnée. Cocher "Mise à jour" pour pouvoir la modifier depuis Home Assistant (uniquement si disponible sur EVOO7). Seules les données en Consultation et/ou Mise à jour font l'objet d'une découverte Home Assistant (et affichent les champs Taxonomie/Classe HA). Un seul bouton 💾 par ligne sauvegarde tous les champs modifiés (sélection, topic/format, taxonomie, classe HA).
